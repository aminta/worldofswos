How to install

A few steps. You need your own copy of SWOS 96/97 (CD or GOG) and the Chrome or Edge browser.

Video: how to install

One-click install on GOG, the Program Files tip, first start with the "SWOS Mod - English.bat" launcher and the CAREER 2026-27 button, update from 4.0, CD version, joypad with your own DOSBox. youtu.be/lmbYbEYYaoM

One-click install

  1. Download the patcher from the release page and open it in Chrome or Edge.

    Download the patcher

    The 4.0.1 release on GitHub · MD5 4775f8df81ea9b8e5aa4cf7476a48b92

  2. Press "Choose the game folder" and pick the game's folder (below: where it is, version by version).
  3. The page recognises your version, puts a copy of the files it changes in the MOD_BACKUP folder and writes the mod in their place. Done: start the game and begin a new career. Run it again to update. Your files never leave your computer.

With Firefox or Safari, use the manual method further down the same patcher page: drop your language's executable and the DATA files, download the patched files and copy them into the game folder (the TEAM files into DATA), after backing it up. If the game is in Program Files, Windows asks for administrator permission when you copy or extract the files into its folder: accept.

Is the game in Program Files (for example GOG Galaxy's folder, C:\Program Files (x86)\GOG Galaxy\Games)? Chrome and Edge do not open that folder ("contains system files"). Use the manual steps, or copy the game folder somewhere else (for example Documents), install the mod into the copy with one click, then copy its contents back over the original (Windows asks for administrator permission: accept) and play as usual.

GOG on Windows

  • With the offline installer the folder is usually C:\GOG Games\Sensible World of Soccer 96-97; with GOG Galaxy C:\Program Files (x86)\GOG Galaxy\Games\Sensible World of Soccer 96-97.
  • Or wherever you installed it: the folder that contains ENGLISH.EXE and SWOS97.dat.

GOG on Mac

  • The folder to pick is deep inside the app (an app inside an app): in Applications, right-click Sensible World of Soccer 9697 → Show Package Contents, then again on the inner app.
  • The full path: Sensible World of Soccer 9697.app/Contents/Resources/game/Sensible World Of Soccer 96-97.app/Contents/Resources/Sensible World Of Soccer 96-97.boxer/C Sensible World of Soccer 96-97.harddisk
  • In the folder picker press Cmd+Shift+G and paste the path.

CD with DOSBox

  • A CD cannot be changed: press "From the CD: copy the game into a new folder", pick the game folder on the CD first (for example D:\SWOS), then an empty folder on your disk (for example C:\SWOS). The page copies the game there and installs the mod.
  • In DOSBox, mount that folder as C: and start the game as always.

Starting the game in Italian, French or German

Do not double-click ITALIAN.EXE or ITALIAN.BAT: they are DOS programs and 64-bit Windows cannot run them; use GOG's shortcut or the launcher file below, which opens the game inside DOSBox.

GOG's "Launch…" shortcut starts the English version. When the one-click install finds GOG's DOSBox, it writes one launcher per language beside the game: "SWOS Mod - Italiano.bat", "SWOS Mod - English.bat", "SWOS Mod - Francais.bat" and "SWOS Mod - Deutsch.bat" (for the languages GOG's folder has a configuration for): start the game with these. A re-run writes back a launcher that was deleted. With the manual install, create a text file in the game folder yourself, name it SWOS-italian.bat (change the extension from .txt to .bat) and paste these 3 lines in it:

@echo off
cd /d "%~dp0DOSBOX"
start "" DOSBox.exe -conf "..\dosbox_SWOS.conf" -conf "..\dosbox_SWOS_single_italian.conf" -noconsole -c "exit"

For French or German replace italian with french or german. Then start the game by double-clicking that file.

Joypad: frequently asked questions

  • GOG: the one-click install has a tick, "GOG version: I have a joypad / gamepad", on by default (it acts only on a GOG folder): the joypad works at once, stick and d-pad. The joypad is player 1 and the keyboard player 2, with a ready calibration. The game checks at start whether a joypad is connected and falls back to the keyboard when there is none, so keyboard players can leave the tick on (the fire key stays Ctrl). The changed files are backed up (.bak): untick it to keep your own controls settings, and running the install again without the tick restores the originals.
  • Your own DOSBox (CD, eXoDOS, other): if you have a joypad, tick the second box, "Using your own DOSBox (CD, eXoDOS, other)?", off by default (it changes only SETUP.DAT, with a .bak copy) and add these lines to your DOSBox configuration: [joystick], joysticktype=2axis, timed=false.
  • Then map the d-pad with DOSBox's mapper (Ctrl+F1; in DOSBox-X: Main > Mapper editor): joystick 1 Y- up, Y+ down, X- left, X+ right (Add, press the direction, Save). In DOSBox-X, if you play with the keyboard only, set joysticktype=none.
  • To calibrate it yourself: the game's INSTALL.EXE (on the CD) > Configure > Control > Calibrate Joystick, or SETUP.EXE (a Windows 3.x program in the game folder).
