Vous avez trouvé un problème dans le mod (la 3.3.6 aussi) ? Dites-le-nous ici. Si possible, joignez la sauvegarde de votre carrière : le fichier .CAR se trouve dans le dossier du jeu. Sur MiSTer, les sauvegardes sont dans l'image disque VHD.

Votre signalement parvient au responsable du mod via Tally et sert uniquement à corriger le bug. Vous avez un compte GitHub ? Ouvrez une issue.
