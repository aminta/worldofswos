Comment installer

Quelques étapes. Il vous faut votre propre copie de SWOS 96/97 (CD ou GOG) et le navigateur Chrome ou Edge.

Ce navigateur ne peut pas faire l'installation en un clic (il faut Chrome ou Edge, version 86 ou plus récente). Vous pouvez installer à la main : utilisez la méthode manuelle ci-dessous, ou ouvrez cette page dans Chrome ou Edge.

Vidéo : comment installer (en anglais)

Installation en un clic sur GOG, l'astuce Program Files, premier lancement avec « SWOS Mod - Francais.bat » et le bouton CARRIÈRE 2026-27, mise à jour depuis la 4.0, version CD, manette avec votre propre DOSBox. youtu.be/lmbYbEYYaoM

Quel dossier choisir ?

Trouvez votre cas ; le patcher veut le dossier qui contient ENGLISH.EXE et SWOS97.dat.

GOG, installateur hors ligneEn général C:\GOG Games\Sensible World of Soccer 96-97. Choisissez-le directement.
GOG Galaxy (Windows)C:\Program Files (x86)\GOG Galaxy\Games\Sensible World of Soccer 96-97 est dans Program Files : Chrome et Edge le refusent. Suivez les étapes Program Files.
GOG sur MacDans l'application : voir le chemin sur Mac (clic droit sur l'app, Afficher le contenu du paquet, deux fois).
CD avec DOSBoxNe choisissez pas le CD : dans le patcher, appuyez sur « Depuis le CD : copier le jeu dans un nouveau dossier ».
Autre DOSBox / eXoDOSLe dossier avec ENGLISH.EXE (celui que vous montez comme C: dans DOSBox).

Installer en un clic

  1. Téléchargez le patcher depuis la page de la version et ouvrez-le dans Chrome ou Edge.

    Télécharger le patcher

    La version 4.1.2 sur GitHub · MD5 15c11e0d7ae4c853f16f3799526bcb20

  2. Cliquez sur « Choisir le dossier du jeu » et indiquez le dossier du jeu (ci-dessous : où il se trouve, version par version).
  3. La page reconnaît votre version, met une copie des fichiers qu'elle modifie dans le dossier MOD_BACKUP et écrit le mod à leur place. C'est fait : lancez le jeu et commencez une nouvelle carrière. Recommencez pour mettre à jour. Vos fichiers ne quittent jamais votre ordinateur.

Avec Firefox ou Safari, utilisez la méthode manuelle, plus bas sur la même page du patcher : déposez l'exécutable de votre langue et les fichiers du dossier DATA, téléchargez les fichiers modifiés et copiez-les dans le dossier du jeu (les fichiers TEAM dans DATA), après en avoir fait une sauvegarde. Si le jeu est dans Program Files / Programmes, Windows demande l'autorisation d'administrateur quand vous copiez ou extrayez les fichiers dans son dossier : acceptez.

Jeu dans Program Files (GOG Galaxy) : pas à pas

Chrome et Edge n'ouvrent pas Program Files (« contient des fichiers système »). On travaille sur une copie : deux minutes suffisent.

  1. Ouvrez C:\Program Files (x86)\GOG Galaxy\Games dans l\'Explorateur et copiez le dossier Sensible World of Soccer 96-97 dans Documents.
  2. Ouvrez le patcher dans Chrome ou Edge, appuyez sur « Choisir le dossier du jeu » et choisissez la copie dans Documents. Attendez « Terminé ».
  3. Ouvrez la copie dans Documents, sélectionnez tout son contenu, copiez-le et collez-le sur le dossier d'origine dans Program Files. Windows demande l'autorisation d'administrateur : acceptez et choisissez « Remplacer les fichiers ».
  4. Jouez avec les lanceurs « SWOS Mod - <langue>.bat » (voir « Lancer le jeu en italien, français ou allemand » plus bas).

Astuce : le patcher peut aussi installer dans un nouveau dossier, ce qui évite la recopie (voir la nouvelle option du patcher).

GOG sur Windows

  • Avec l'installateur hors ligne, le dossier est en général C:\GOG Games\Sensible World of Soccer 96-97 ; avec GOG Galaxy, C:\Program Files (x86)\GOG Galaxy\Games\Sensible World of Soccer 96-97.
  • Ou là où vous l'avez installé : le dossier qui contient FRENCH.EXE et SWOS97.dat.

GOG sur Mac

  • Le dossier à choisir se trouve au fond de l'application (une application dans une application) : dans Applications, clic droit sur Sensible World of Soccer 9697 → Afficher le contenu du paquet, puis de nouveau sur l'application intérieure.
  • Le chemin complet : Sensible World of Soccer 9697.app/Contents/Resources/game/Sensible World Of Soccer 96-97.app/Contents/Resources/Sensible World Of Soccer 96-97.boxer/C Sensible World of Soccer 96-97.harddisk
  • Dans la fenêtre de choix du dossier, appuyez sur Cmd+Maj+G et collez le chemin.

CD avec DOSBox

  • Un CD ne peut pas être modifié : cliquez sur « Depuis le CD : copier le jeu dans un nouveau dossier », choisissez d'abord le dossier du jeu sur le CD (par exemple D:\SWOS), puis un dossier vide sur votre disque (par exemple C:\SWOS). La page y copie le jeu et installe le mod.
  • Dans DOSBox, montez ce dossier comme C: et lancez le jeu comme d'habitude.

Lancer le jeu en italien, en français ou en allemand

Ne double-cliquez ni sur ITALIAN.EXE ni sur ITALIAN.BAT : ce sont des programmes DOS et Windows 64 bits ne peut pas les lancer ; utilisez le raccourci de GOG ou le fichier de lancement ci-dessous, qui ouvre le jeu dans DOSBox.

Le raccourci « Launch… » de GOG démarre la version anglaise. Quand l'installation en un clic trouve le DOSBox de GOG, elle écrit à côté du jeu un lanceur par langue : « SWOS Mod - Italiano.bat », « SWOS Mod - English.bat », « SWOS Mod - Francais.bat » et « SWOS Mod - Deutsch.bat » (pour les langues dont le dossier de GOG a une configuration) : lancez le jeu avec eux. Une nouvelle exécution réécrit un lanceur supprimé. Avec l'installation manuelle, créez vous-même dans le dossier du jeu un fichier texte, nommez-le SWOS-francais.bat (changez l'extension .txt en .bat) et collez-y ces 3 lignes :

@echo off
cd /d "%~dp0DOSBOX"
start "" DOSBox.exe -conf "..\dosbox_SWOS.conf" -conf "..\dosbox_SWOS_single_french.conf" -noconsole -c "exit"

Pour l'italien ou l'allemand, remplacez french par italian ou german. Lancez ensuite le jeu en double-cliquant sur ce fichier.

Premier match : la liste courte

  1. Lancez le jeu avec le lanceur de votre langue, pas avec le raccourci GOG (il lance toujours l'anglais).
  2. Dans le menu principal, appuyez sur CARRIÈRE 2026-27 (nouvelle carrière : les anciennes sauvegardes gardent les anciens effectifs).
  3. Choisissez votre club et jouez. Commandes : flèches et Ctrl ; avec une manette, voir la section manette plus bas.
  4. Un problème ? Vos fichiers d'origine sont dans MOD_BACKUP dans le dossier du jeu ; relancez le patcher pour mettre à jour, ou signalez un bug.

Manette : questions fréquentes

  • GOG : l'installation en un clic a une case, « Version GOG : j'ai une manette / un gamepad », cochée par défaut (elle n'agit que sur un dossier GOG) : la manette fonctionne tout de suite, stick et croix directionnelle. La manette est le joueur 1 et le clavier le joueur 2, avec une calibration prête. Le jeu vérifie au démarrage si une manette est branchée et passe au clavier s'il n'y en a pas : les joueurs au clavier peuvent laisser la case cochée (la touche de tir reste Ctrl). Les fichiers modifiés sont sauvegardés (.bak) : décochez la case pour garder vos propres réglages de commandes, et relancez l'installation sans la case pour remettre les originaux.
  • Manette en mode clavier (GOG) : pour les joysticks qui marchent dans les menus mais, en match, ne vont qu'en haut et à gauche, l'installation a une troisième case, « Version GOG, manette en mode clavier », décochée par défaut et utilisée avec la première. Le stick, la croix directionnelle et les boutons deviennent les flèches et Ctrl : pas de calibration, tout joystick fonctionne, et manette et clavier commandent tous deux le joueur 1. Décochez-la et réinstallez pour revenir à la manette calibrée.
  • Menu COMMANDES dans le jeu (4.0.2) : OPTIONS a un bouton COMMANDES (entre ESCI A DOS et ESCI). Vous y choisissez l'entrée (clavier seul, manette 1 + clavier 2, clavier 1 + manette 2, deux manettes), réglez chaque touche en l'appuyant, calibrez la manette et sauvegardez (dans le SETUP.DAT du jeu). Avec SWOS++, le bouton n'existe pas.
  • Votre propre DOSBox (CD, eXoDOS, autre) : si vous avez une manette, cochez la deuxième case, « Vous utilisez votre propre DOSBox (CD, eXoDOS, autre) ? », décochée par défaut (elle ne modifie que SETUP.DAT, avec une copie .bak) et ajoutez ces lignes à la configuration de votre DOSBox : [joystick], joysticktype=2axis, timed=false.
  • Associez ensuite la croix directionnelle avec le mappeur de DOSBox (Ctrl+F1 ; dans DOSBox-X : Main > Mapper editor) : joystick 1 Y- haut, Y+ bas, X- gauche, X+ droite (Add, appuyez sur la direction, Save). Dans DOSBox-X, si vous jouez uniquement au clavier, mettez joysticktype=none.
  • Pour la calibrer vous-même : INSTALL.EXE du jeu (sur le CD) > Configure > Control > Calibrate Joystick, ou SETUP.EXE (programme Windows 3.x dans le dossier du jeu).
