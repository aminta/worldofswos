So wird installiert

Wenige Schritte. Du brauchst deine eigene Kopie von SWOS 96/97 (CD oder GOG) und den Browser Chrome oder Edge.

Installation mit einem Klick

  1. Lade den Patcher von der Release-Seite herunter und öffne ihn in Chrome oder Edge.

    Patcher herunterladen

    Die Version 4.0 auf GitHub · MD5 d0947893c8f9b8da99a7bcd37c5c318f

  2. Klicke auf „Spielordner wählen“ und wähle den Ordner des Spiels (unten: wo er liegt, Version für Version).
  3. Die Seite erkennt deine Version, legt eine Kopie der Dateien, die sie ändert, im Ordner MOD_BACKUP ab und schreibt die Mod an ihre Stelle. Fertig: Starte das Spiel und beginne eine neue Karriere. Zum Aktualisieren einfach wiederholen. Deine Dateien verlassen nie deinen Computer.

Mit Firefox oder Safari nimm die manuelle Methode weiter unten auf derselben Patcher-Seite: Zieh die ausführbare Datei deiner Sprache und die Dateien aus DATA hinein, lade die gepatchten Dateien herunter und kopiere sie in den Spielordner (die TEAM-Dateien nach DATA), nachdem du ihn gesichert hast. Liegt das Spiel unter Programme / Program Files, fragt Windows beim Kopieren oder Entpacken der Dateien in seinen Ordner nach Administratorrechten: bestätigen.

Liegt das Spiel unter Programme / Program Files (zum Beispiel im Ordner von GOG Galaxy, C:\Program Files (x86)\GOG Galaxy\Games)? Chrome und Edge öffnen diesen Ordner nicht („enthält Systemdateien“). Folge den Schritten von Hand, oder kopiere den Spielordner woandershin (zum Beispiel nach Dokumente), installiere die Mod mit einem Klick in die Kopie, kopiere dann ihren Inhalt über das Original zurück (Windows fragt nach Administratorrechten: bestätigen) und spiel wie gewohnt.

GOG unter Windows

  • Mit dem Offline-Installer ist der Ordner meist C:\GOG Games\Sensible World of Soccer 96-97, mit GOG Galaxy C:\Program Files (x86)\GOG Galaxy\Games\Sensible World of Soccer 96-97.
  • Oder wo du es installiert hast: der Ordner mit GERMAN.EXE und SWOS97.dat.

GOG auf dem Mac

  • Der zu wählende Ordner liegt tief in der App (eine App in der App): In Programme Rechtsklick auf Sensible World of Soccer 9697 → Paketinhalt zeigen, dann noch einmal bei der inneren App.
  • Der vollständige Pfad: Sensible World of Soccer 9697.app/Contents/Resources/game/Sensible World Of Soccer 96-97.app/Contents/Resources/Sensible World Of Soccer 96-97.boxer/C Sensible World of Soccer 96-97.harddisk
  • Im Ordner-Auswahlfenster Cmd+Umschalt+G drücken und den Pfad einfügen.

CD mit DOSBox

  • Eine CD lässt sich nicht ändern: Klicke auf „Von der CD: Spiel in einen neuen Ordner kopieren“, wähle zuerst den Spielordner auf der CD (zum Beispiel D:\SWOS), dann einen leeren Ordner auf deiner Festplatte (zum Beispiel C:\SWOS). Die Seite kopiert das Spiel dorthin und installiert die Mod.
  • In DOSBox diesen Ordner als C: einbinden und das Spiel wie gewohnt starten.
